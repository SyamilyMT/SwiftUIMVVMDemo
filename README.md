# SwiftUIMVVMDemo

## SwiftUI + MVVM

Welcome to the SwiftUIMVVMDemo repository! This sample app is designed to showcase various programming concepts, including SOLID principles, MVVM architecture and new interface framework SwiftUI.

## Purpose

The primary goal of this repository is to provide a comprehensive understanding of essential programming principles and demonstrate their implementation within a SwiftUI project. The current application list various cities inside Australia grouped by corresponding states. And we have an option to reverese the list as well.

- **MVVM Architecture**: Understand the Model-View-ViewModel architecture and its implementation in Swift.
- **SOLID Principles**: Learn about writing maintainable and scalable code by applying SOLID principles.
- **SwiftUI**: See how a single ViewModel can be connected to SwiftUI frameworks.
- **Unit Tests**: Learn about writing unit tests to ensure code quality and reliability.

## Getting Started

To get started with this demo project, follow these steps:

1. **Clone the Repository**: Clone this repository to your local machine.
2. **Explore the Code**: Dive into the codebase to explore the various concepts implemented.
3. **Run the Project**: Run the project in Xcode to see the sample app in action.
4. **Check Unit Tests**: Review the unit tests to understand how different functionalities are tested.
